# wavekol-creator-lifecycle

**带货者生命周期管理** —— 线索→评估→试播→稳定开播→预警→停播→召回，每个状态有负责人和下一步

让 AI agent（DSH / Codex / Claude Code 等）使用。

## 解决什么问题

之前带货者试播完常常没人跟进，状态不清、责任不清、下一步不清。

现在每个带货者处在清晰状态（线索 / 评估 / 试播准备 / 试播中 / 稳定开播 / 预警 / 停播 / 召回），有负责人、有下一步、有截止时间。

## 前置依赖

无需额外依赖，直接可用。

## 安装

```bash
git clone https://github.com/DaJunn/wavekol-creator-lifecycle.git \
  ~/.agents/skills/wavekol-creator-lifecycle
```

## 触发方式

对 agent 说：「带货者建档」「试播跟进」「带货者转正」「带货者停播」「带货者状态表」「谁该跟进」。


## 说明

- **试播跟进是跟播运营的本职**，这个 skill 把它固化了
- 统一称「带货者」，不写「主播」「达人」
