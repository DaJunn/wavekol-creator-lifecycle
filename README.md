# 带货者生命周期管理

梳理带货者当前阶段、负责人和下一步，减少试播后无人跟进、状态不清的问题。

面向支持 `SKILL.md` 的 AI agent；详细执行规则见 [SKILL.md](SKILL.md)。

## 安装

将仓库放入所用 agent 的技能目录。以下为 `~/.agents/skills` 示例；目录已存在时先查看已有修改，再决定更新方式。

```bash
git clone https://github.com/DaJunn/wavekol-creator-lifecycle.git \
  ~/.agents/skills/wavekol-creator-lifecycle
```

## 开始使用

提供相关档案、沟通或复盘材料即可开始。读取或更新飞书时，需相应工具和访问权限。

对 agent 说：

> 请根据这份档案和最近两场复盘，整理各带货者的当前状态、跟进人、下一步和待确认事项。

## 交付内容

状态与证据、负责人、下一步、截止时间及待确认事项。

本仓库提供工作流指引，不附带自动同步脚本；在线集成依赖环境中已安装的工具。结果以实际可访问的资料为准，缺失信息会标记待确认。
